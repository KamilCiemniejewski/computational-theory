# Computational-theory
This repository contains my Computational Theory assessment. The assessment focuses on understanding and implementing the SHA-256 hashing algorithm using Python.

The main work is completed in a Jupyter Notebook called `problems.ipynb`. It contains explanations, Python code and examples for assessment problems.

# Requirements
To run this project, you will need:

- Python 3
- Jupyter Notebook
- NumPy

The required Python packages are listed in `requirements.txt`.

# How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook problems.ipynb
   ```

5. Run the notebook cells in order.
